BSPMR 1st Annual Scientific Conference 2026 — Website
=====================================================

HOW TO OPEN
  Unzip the folder, then double-click  index.html
  It opens in your browser like a real website - no server or installation needed.
  (Keep all files together in the same folder.)

PAGES
  index.html          Home
  about.html          About & Committees
  program.html        Scientific Program
  speakers.html       Speakers
  abstract.html       Abstract Submission
  registration.html   Registration
  notices.html        Notices & Downloads
  gallery.html        Gallery
  contact.html        Contact Us
  assets/             logo and site script

TO PUT IT ONLINE
  Upload the whole folder to any web hosting (cPanel, Netlify, GitHub Pages...).
  index.html becomes the home page.

NOTES
  * Front-end prototype: registration, payment, abstract submission and status
    check show demo screens only (no backend, payment gateway or email yet).
  * Text in [square brackets] is placeholder content for BSPMR to provide.
  * Needs an internet connection for the web fonts (Sora & Manrope).
